Offline network data (used to name the network and country behind public IP addresses)

Bundled:
  dbip-asn-lite-2026-10.mmdb      IP to ASN Lite (October 2026)
  dbip-country-lite-2026-10.mmdb  IP to Country Lite (October 2026)

IP Geolocation by DB-IP - https://db-ip.com

every finding and in METHODS.md.

To update (optional, on an internet-connected machine): download the newest "IP to ASN Lite" and
"IP to Country Lite" files in MMDB format from https://db-ip.com/db/lite.php, unzip them, copy them
here and delete the old ones. Any MaxMind-format .mmdb file works (for example GeoLite2-ASN and
GeoLite2-Country, if your agency licenses them). Keep at most one ASN and one country/city file.

Remember that registrations change: the data describes who held an address when the database was
built, not necessarily on the date of an event.
